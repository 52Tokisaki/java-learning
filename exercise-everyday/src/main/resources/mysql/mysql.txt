1. 了解过索引吗（什么是索引）
索引（index）是帮助MYSQL高效获取数据的数据结构（有序）
提高数据的检索效率，降低数据库的IO成本（不需要全表扫描）
通过索引对数据进行排序，降低数据排序的成本，降低CPU的消耗

2. 索引的底层数据结构
MySQL的InnoDB引擎采用的B+树数据结构存储索引
阶数更多，路径更短
磁盘读写B+树代价更低，非叶子节点仅存储指针，叶子节点存储数据
B+树便于扫库和区间查询，叶子节点是一个双向链表

3. 聚簇索引 & 非聚簇索引
聚簇索引： 数据和索引放在一块，B+树的叶子节点保存了整行数据，有且只有一个
非聚簇索引（二级索引）： 数据和索引分开存储， B+树的叶子节点保存对应主键， 可以有多个

4. 什么是回表查询
通过二级索引找到对应的主键值，再到聚簇索引中找到整行数据，这个过程就是回表查询

5. 什么是覆盖索引
覆盖索引是指查询使用了索引，返回的列必须在索引中能够全部找到
使用id查询，直接走聚簇索引查询，一次索引扫描，直接返回数据，性能高
如果返回的列中没有创建索引，可能触发回表查询，因此尽量避免使用select *

6. MySQL超大分页查询怎么处理
数据量比较大时， limit分页查询，需要对数据进行排序，效率低
可以使用覆盖索引 + 子查询
select * from table1 t , (select id from table1 order by id limit 9000000, 10)  a where t.id = a.id;

7.索引创建的原则有哪些
a、数据量较大，且查询比较频繁的表
b、常作为查询条件、排序、分组的字段
c、字段内容区分度高
d、内容较长，使用前缀索引
e、尽量联合索引
f、要控制索引的数量
g、如果索引列不能存储NULL值，在创建表时用NOT NULL约束它
